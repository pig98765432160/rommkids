# 嗄歐麥麥ROMM

一個小角落，分享遊戲與動漫的趣味世界！  
使用者可以瀏覽、收藏、留言，打造自己的動漫遊戲分享空間。

Current website:  
[https://rommkids.vercel.app](https://rommkids.vercel.app)

## Development

- This is a `Next.js` project bootstrapped with `create-next-app`.
- This project is using [pnpm](https://pnpm.io/) as the package manager.

> ### 📌 **Important: Please use `pnpm` to install the dependencies.**
>
> Run the following command:
>
> ```bash
> pnpm install
> ```

#### Other scripts

- `pnpm run dev` - Start the development server
- `pnpm run build` - Build the project
- `pnpm run start` - Finish Build the project and Start production server

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Installation and Usage

Prerequisites: `Node.js (v20.19.4)`,

```js
 dependencies: {
   "next": "13.1.1",
   "react": "18.3.1",
   ...
 }
```

## Environment Variables

Set the environment variables in `.env` file.

```bash
NEXT_PUBLIC_BASE_URL=<NEXT_PUBLIC_BASE_URL>
YOUTUBE_CHANNEL_ID=<YOUTUBE_CHANNEL_ID>
YOUTUBE_API_KEY=<YOUTUBE_API_KEY>
FIREBASE_PROJECT_ID=<FIREBASE_PROJECT_ID>
FIREBASE_CLIENT_EMAIL=<FIREBASE_CLIENT_EMAIL>
FIREBASE_PRIVATE_KEY=<FIREBASE_PRIVATE_KEY>
```
